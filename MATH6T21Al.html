WARM-UP

Aling Rosa's Secret Mix!

🥭 🥭 : 🥛 🥛 🥛

2 cups of mango puree to 3 cups of water — we are COMPARING two quantities!

2 : 3"2 to 3"2/3

Three ways to write the same comparison — and a ratio compares by multiplication/division, never by addition!

KEY IDEA

What is a RATIO?

A RATIO compares two quantities with the same units. In 2:3, the 2 = first quantity, the 3 = second quantity.

🥭:🥛 = 2:3≠🥛: = 3:2

ORDER MATTERS — same numbers, different meaning! Write quantities in the order the question asks.

2:3=4:6=6:9

Multiply BOTH by the same number → EQUIVALENT RATIOS (same comparison, bigger batch)!

MODEL 1 📊

The Ratio Table!

🥭 MANGO PUREE🥛 WATER 23 46 69 812
×2 → 4:6×3 → 6:9×4 → 8:12

Both columns grow by the SAME multiplier — so every row keeps the ratio 2:3!

Missing value? Find the multiplier on one column (2→6 = ×3), then apply it to the other (3→9)!

KEY IDEA 2

Proportion = Equal Ratios!

2 : 3=4 : 6

A PROPORTION is an equation saying two ratios are equal.

2×6 = 12=3×4 = 12

Draw an X (cross-multiply): equal cross products → TRUE proportion ✔; different → NOT a proportion.

MODEL 2 📏

The Double Number Line!

0 2 4 6 0 3 6 9

Top: cups of mango puree 🥭 • Bottom: cups of water 🥛 — matching pairs line up vertically!

2→3, 4→6, 6→9: the line shows 2:3 = 4:6!

Missing value? Use the SAME multiplier on both lines: 2→4 is ×2, so 3→6. Same distance, same multiplier!

SITUATION A 🥚

Eggs & Flour — Table It!

"A recipe uses 2 eggs for every 3 cups of flour."

Ratio = 2:3. If the baker uses 6 eggs, how much flour? Read the table! ➜

🥚 EGGS🌾 FLOUR 23 46 69

6 eggs → 9 cups flour ✔

WHY it works: eggs 2→6 is ×3, so flour 3→9 is ×3 too. The ratio 2:3 never changes — that's proportional reasoning!

SITUATION B 💰

Juice Packs — Line It!

01 23 4 ₱0₱10 ₱20₱30 ₱40

UNIT RATE: every 1 pack adds ₱10 → 1 pack = ₱10. So 4 packs = 4×10 = ₱40!

2:20=4:40

Cross products: 2×40 = 80 and 20×4 = 80 → TRUE proportion ✔

Juice Bar Hazards! 🕳️

Hazard 1 • Order

stars:hearts is NOT hearts:stars — order matters! Always match the question's order.

Hazard 2 • Units

compare only same units (cups with cups, pesos with pesos) before writing a ratio.

Hazard 3 • Grow rule

in proportions, multiply BOTH quantities by the same number — never just add!
